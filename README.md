# Güzellik Merkezi Randevu Sistemi 

Bu proje, güzellik merkezleri için geliştirilmiş kapsamlı bir randevu yönetim sistemidir. Müşterilerin kolayca randevu alabilmesini sağlayan bir mobil uygulama ve işletme sahiplerinin randevuları, personeli ve hizmetleri yönetebildiği bir web yönetim panelinden oluşmaktadır.

## 🚀 Özellikler

* **Kullanıcı Uygulaması:** Müşterilerin uygun saatleri görüp randevu oluşturabilmesi.
* **Yönetim Paneli:** İşletme sahibinin randevuları onaylaması, iptal etmesi ve takvimi görüntülemesi.
* **API Entegrasyonu:** Mobil ve web platformlarının eşzamanlı ve sorunsuz haberleşmesi.

## 🛠️ Kullanılan Teknolojiler

* **Backend / Web Panel:** ASP.NET MVC
* **Veritabanı:** SQL Server 
* **API:** RESTful API mimarisi


## 💻 Kurulum (Nasıl Çalıştırılır?)

Projeyi kendi bilgisayarınızda çalıştırmak için:
1. Repoyu klonlayın: `git clone https://github.com/peeliin/randevu_sistemi.git`
2. Backend projesini Visual Studio'da açıp veritabanı bağlantı (Connection String) ayarlarını kendi lokal sunucunuza göre güncelleyin.
3. Package Manager Console üzerinden `Update-Database` komutu ile veritabanını oluşturun.
4. Flutter projesini VS Code veya Android Studio ile açıp `flutter pub get` komutu ile paketleri yükleyin.
